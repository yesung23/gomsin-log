# AI Usage Policy for Shared Control Tower

- This vault is parked inside the gomsin-log repository for convenience.
- The repository root remains the canonical product/engineering source of truth.
- control-tower/ is documentation, navigation, and shared context only.
- No agent may create a second source of truth here.
- Do not store secrets, service keys, or production credentials.
- Do not commit machine-specific Obsidian workspace files (workspace.json, cache, etc.).
- Keep reports factual and bounded to the actual work performed.
