# Cycle · Care Canon — 코드를 보기 전에 통과시킬 질문

> **답을 여기 옮겨 적지 않았다.** 주기·배려 결정의 집은 `docs/PRODUCT_V3.md`
> §13 · §20 · §21이다. 그 규칙을 이 페이지에 복사하면 두 번째 source of truth가 되고,
> 정책이 바뀔 때 여기만 옛말로 남는다 — [[AI_ENTRYPOINT]]가 금지하는 것이다.
>
> 이 페이지가 하는 일은 **무엇을 물어야 하는지 빠뜨리지 않게 하는 것**이다.
> 이 영역은 제품 결정이 촘촘해서, 코드만 보고 짐작하면 반드시 틀린다.

## 짓기 전에 통과시킨다

| 물어야 할 것 | 답이 있는 곳 |
|---|---|
| 출혈량을 파트너가 볼 수 있나 | §21 *공유 매트릭스* |
| 통증 단계를 파트너가 볼 수 있나 | §21 *공유 매트릭스* · §20 *데이터 분류 매트릭스* |
| 증상 · 기분 · 비공개 메모는 | §21 · §20 |
| 컨디션 신호(`feeling_unwell`)는 주기 데이터인가 별개인가 | §21 *배려 표현은 주기에서 파생하지 않는다* |
| 증상에서 배려 신호를 자동으로 만들어도 되나 | §21 같은 절 · §13 *감정 · 기계 추론* |
| 배려 요청에 사용자의 명시적 의도가 필요한가 | §13 — 파트너에게 보이는 것은 **작성자의 명시적 행위**를 요구한다 |
| 가임 기간을 어떻게 표시하나 | §21 *공유 매트릭스* — 무엇을 함께 고지해야 하는지 포함 |
| 피임 · 임신 · 안전일을 말해도 되나 | §21 고지 문구 · `docs/PRODUCT_V3.md` §16 *명시적 비목표* |
| 증상만 기록한 것이 예측을 바꿔도 되나 | §21 *불변 규칙* |
| projection을 누가 만들고 무엇으로 감싸나 | §21 *불변 규칙* — HRK 원본을 CSK로 다시 감싸는 경로 |
| 동의를 철회하면 이미 내려간 데이터는 | §21 *불변 규칙* |
| 웹에서 건강 도메인이 꺼져 있는 것은 결함인가 | §21 *불변 규칙* — 결함이 아니라 명시된 정책 |

**표에 없는 질문이 생겼다면** 그건 §22 *열린 제품 결정*이거나 아직 아무도 정하지 않은
것이다. 코드로 먼저 정하지 않는다 — [[Do Not Build]].
