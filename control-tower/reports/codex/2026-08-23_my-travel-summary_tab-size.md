# 2026-08-23 — 우리 여행 요약과 프로필 탭 크기 안정화

## 요청

`우리`의 `여행` 탭도 안에서 간단히 보이고, 중간 `사진` 탭을 열 때 선택 상태가 커져
보이지 않게 조정한다.

## 변경

- `우리 → 여행`에 기존 `state.trips`를 재사용한 요약 목록을 추가했다.
  현재·예정·지난 순서로 최대 세 개를 보여주고, 각 카드는 여행 상세로 간다. 전체 목록은
  기존 `/trips`가 계속 소유한다.
- 여행이 없을 때는 등록된 여행이 없다는 상태와 여행 플래너 진입만 보여준다. 날짜나 여행을
  만들어 내지 않는다.
- 프로필 세 탭에 비활성 상태도 같은 아래 테두리 공간을 예약하고, 포커스 링을 탭 안쪽으로
  넣었다. 선택된 탭이 주변보다 커 보이거나 탭 줄을 밀지 않는다.
- 기존 사진 기록 목록과 사진 전용 게시물 격자는 변경하지 않았다.
