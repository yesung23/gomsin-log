> **이 문서의 지위.** 장기 비즈니스 방향과 수익화 가설을 담는다. 제품의 코어
> 루프·비목표는 [`PRODUCT_V3.md`](PRODUCT_V3.md)가 canonical이고, 구현 순서는
> [`ENGINEERING_ROADMAP.md`](ENGINEERING_ROADMAP.md)가 canonical이다.
> 이 문서는 가격·사업 모델·기억 제품 가설의 authoritative home이다.
>
> **가격은 전부 초기 가설이다.** 아래의 금액·원가·전환율은 검증 전 가설이며
> 코드·마이그레이션·제품의 무료 경계에 하드코딩하지 않는다.
>
> 기준일: 2026-08-14. 코드·마이그레이션·가격 로직 없음 — 순수 방향 문서.

## 1. 핵심 사업 원칙

1. **연결과 보존은 무료로 제공한다.** 기록, 코어 채팅, 상대방의 오늘, 정확한 원본,
   반응, 이따 이야기하기, 핵심 일정, E2EE와 프라이버시 제어를 유료 장벽으로 만들지
   않는다.
2. **과금은 바이트가 아니라 가치 창출에 둔다.** 함께 쌓아온 시간을 고르고, 정리하고,
   편집하고, 보기 좋게 만들고, 디지털 또는 실물 기억 제품으로 제작하는 경험이 유료
   가치다.
3. **정상적인 보존을 일부러 약화시키지 않는다.** 미디어를 보존할 수 있는 기능을
   기술적으로 지원하되, 저장용량 부족을 수익화하기 위해 화질·접근·내보내기를
   인위적으로 막지 않는다.
4. **구독을 시작점으로 가정하지 않는다.** 초기 수익의 중심은 일회성 디지털·실물
   기억 제품이며, 반복형 Plus는 매달 새로운 가치가 증명될 때만 검토한다.
5. **AI는 편집자이지 심판이 아니다.** 관계 품질, 감정, 기억 중요도를 점수화하지 않는다.
6. **광고·참여 조작을 중심으로 삼지 않는다.** 사용자를 오래 붙잡거나 메시지 수를 늘리는
   것이 목표가 아니다.

## 2. 새로운 비즈니스 모델

```text
FREE CORE
  + ONE-TIME DIGITAL MEMORY PRODUCTS
  + PHYSICAL MEMORY PRODUCTS
  + OPTIONAL PLUS LATER
```

제품의 핵심 흐름은 다음과 같다.

```text
무료로 하루를 이어감
→ 기록과 사진이 자연스럽게 쌓임
→ 사람이 중요한 기억을 선택
→ 기념일·전역·여행 등 구매 순간 발생
→ 디지털 또는 실물 기억 제품 제작
→ 사용자가 곰신로그를 오래 사용할 이유 강화
```

이 플라이휠은 참여 조작이나 강제 기록 루프가 아니다. 사용자가 실제로 남기고 싶은
순간이 생겼을 때만 선택·제작 단계가 열린다.

## 3. FREE CORE

항상 무료로 유지하는 것:

- 하루 기록
- 둘만의 코어 채팅
- `상대방의 오늘`
- 정확한 원본 이동
- 반응과 `이따 이야기하기`
- 핵심 일정·D-Day
- E2EE와 보안·프라이버시 제어
- 정상적인 사진·미디어 보존 기능(기술적으로 지원되는 범위)
- 기본 데이터 export와 삭제 등 데이터 권리 기능

곰신로그가 자체 저장용량 quota를 판매하기 위해 사용자의 iCloud 미디어를 일부러
압축하거나, 원본 접근·내보내기를 차단하거나, 정상적인 보존 기능을 약화시키지 않는다.
기술적 안전 한도나 플랫폼 제약은 정직하게 설명할 수 있지만, 그것은 저장용량 구독
사업의 근거가 아니다.

## 4. 미디어 저장 전략 — iOS-first

### 전략 방향

```text
사용자 기기
→ 메타데이터·프라이버시 전처리
→ 곰신로그 E2EE
→ 사용자의 iCloud / CloudKit 미디어 저장
→ 승인된 공유 구조를 통한 파트너 접근
```

곰신로그는 **iCloud 용량을 판매하거나 재판매하지 않는다.** 사용자의 iCloud quota가
부족하면 제품은 그 사실과 필요한 사용자 조치를 정직하게 안내한다. 곰신로그 storage
tier를 upsell하는 방식으로 해결하지 않는다.

### 역할 경계

- **사용자 기기:** 사진·미디어의 프라이버시 전처리, EXIF/GPS 처리, 암호화,
  복호화와 가능한 범위의 썸네일·프리뷰 처리
- **iCloud/CloudKit:** 사용자 소유 미디어의 플랫폼 저장 및 승인된 공유 기반
- **Supabase:** Auth, Postgres, 관계, RLS, 최소 조율 메타데이터, 승인된 암호 라우팅·
  키 상태
- **곰신로그:** 관계 맥락, 사용자가 고른 기억, 편집·레이아웃·제작 경험

정확한 CloudKit·CKAsset·CKShare 계약, encrypted blob lifecycle, 파트너 공유,
quota exceeded, unlink/delete, device loss, iCloud unavailable, offline retry,
legacy Supabase Storage 처리, Android 경계는 `ENGINEERING_ROADMAP.md`의
`ARCH-P6`에서 검증한다. 이 문서는 특정 CloudKit API 구현이 이미 존재한다고 주장하지
않는다.

### 플랫폼 경계

iOS-first는 초기 전략이지 Android 사용자의 가치를 폐기한다는 뜻이 아니다. Android에서
사용자 소유 미디어와 파트너 공유를 어떻게 제공할지는 ARCH-P6에서 별도 결정한다.
검증 전에는 호환성·동기화·복구를 약속하지 않는다.

## 5. 주요 수익 — 기억 제품

### 핵심 monetization moment

```text
정상적인 무료 사용
→ 시간이 쌓임
→ 의미 있는 milestone
→ 사용자가 기억을 직접 선택
→ 곰신로그가 가치 있는 결과물을 제작
```

후보 구매 순간:

- 30일·100일·200일
- 연애 기념일·생일
- 입대·첫 휴가·전역
- 장거리 관계 milestone
- 여행
- 특별한 통화·대화·기다림의 순간

초기 군 복무 커플 시장에서는 **전역**이 특히 강한 구매 occasion이 될 수 있다. 단,
수요 검증 전의 가설이다.

### A. 디지털 기억 제품

- 사용자가 선택한 기록·사진·대화·책갈피·milestone
- 큐레이션된 레이아웃
- 사용자가 편집·재정렬·삭제 가능
- 디지털 기억책 또는 디자인된 output

초기 가격 가설: **3,900–7,900 KRW 일회성**. `INITIAL HYPOTHESIS — VALIDATE BEFORE
LAUNCH`로만 취급하며 제품 로직에 하드코딩하지 않는다.

### B. 실물 기억 제품

- POD 인쇄
- 선택한 기억만 포함
- 배송 포함 일회성 구매
- 가격은 실제 POD 원가·배송·지원 비용과 목표 margin을 확인한 뒤 정한다

곰신로그가 처음부터 인쇄 장비나 자체 물류를 소유한다고 가정하지 않는다.

### C. 미래의 디자인 기억 영상

사용자가 선택한 기록·사진·대화로 만든 편집 결과물이다. raw storage나 재생 시간 quota를
판매하는 모델이 아니다. 외부 처리나 export가 필요할 경우 명시적 opt-in과 선택 콘텐츠
경계를 적용한다.

## 6. OPTIONAL PLUS — 가치가 증명된 뒤

Plus는 선택 사항이며 초기 출시의 전제가 아니다. 다음 질문에 `예`라고 답할 수 있을 때만
검토한다.

> **"사용자가 매달 반복해서 받는 새로운 가치가 있는가?"**

가능한 recurring value:

- 반복형 월간/연간 기억 큐레이션
- 고급 archive exploration
- 프리미엄 테마·위젯·커플 커스터마이징
- 더 풍부한 history presentation
- 추가 Book Studio template
- 기억 제품 할인·credit
- 향상된 local/on-device 기억 정리

Plus에 넣지 않는 것:

- 100GB·300GB storage tier
- 원본 사진 화질 자체
- 돈을 냈다는 이유만으로 더 긴 video
- 돈을 냈다는 이유만으로 audio/video 사용 가능 여부
- core E2EE·기록·채팅·Partner Day·privacy control

구독이 반복 가치를 증명하지 못하면 일회성 기억 제품을 우선한다.

## 7. 메모리 제품과 인간의 의도

사용자가 직접 고른 것이 기억 제품의 원재료다.

- 기록 하나
- 사진 하나
- 채팅의 한 순간
- `책에 남기기` 또는 북마크
- 기념일·전역·첫 휴가 같은 milestone

사용자가 선택적으로 “왜 이 장면을 남기고 싶은가?”를 적을 수 있다. 앱이 숨은 중요도
점수로 관계의 가치를 판정하거나, 사람 대신 “최고의 순간”을 결정하지 않는다.

Book Studio는 다음 단계로 둔다.

1. **Stage 1 — AI 없음:** 선택 콘텐츠로 결정론적 초안 생성, 사용자가 편집
2. **Stage 2 — AI 편집자:** 실제 주문 수요와 사용 가치가 확인된 뒤에만 도입

AI의 역할은 편집자·정리 보조·인터뷰어다. 관계 평가자, 감정 분석가, 중요도 oracle,
이별 예측기가 아니다.

## 8. 프라이버시 경계

장기 기억의 가치가 커질수록 E2EE와 사용자 통제가 더 중요해진다.

- 일반 콘텐츠를 서버에서 자동 복호화해 외부 모델로 보내지 않는다.
- AI Book Studio는 선택 콘텐츠에 대한 명시적 opt-in이다.
- 인쇄는 선택 콘텐츠에 한한 E2EE 경계 밖 export임을 설명한다.
- 전체 archive를 자동으로 외부 처리하거나 인쇄하지 않는다.
- 사용자의 데이터 export는 권리·안전 기능이며 유료 디자인 제품이 아니다.

상세 암호 프로토콜은 [`E2EE_PHASE_1A_ARCHITECTURE_V2_1.md`](E2EE_PHASE_1A_ARCHITECTURE_V2_1.md),
개인정보·법적 경계는 [`DATA_LEGAL_E2EE_ARCHITECTURE_DECISION_2026-08-11.md`](DATA_LEGAL_E2EE_ARCHITECTURE_DECISION_2026-08-11.md)가 소유한다.

## 9. 단계적 롤아웃

이 문서는 `ENGINEERING_ROADMAP.md`의 순서를 앞당기지 않는다.

1. 현재: P0–P5 — 핵심 루프, 보안 기반, `daily_records` E2EE
2. `ARCH-P6` — iCloud-first 암호화 미디어 architecture 검증
3. 사진 — upload/share/download/decrypt/delete/unlink lifecycle 증명
4. 오디오 — 사진 기반이 안정된 뒤
5. 영상 — 오디오와 미디어 비용·복구·프라이버시가 검증된 뒤
6. Book Studio Stage 1 — 기억 제품 수요가 확인된 뒤
7. Book Studio Stage 2 및 실물 제품 확장 — Stage 1·POD 수요 검증 뒤

오디오·영상은 저장용량 premium gate가 아니라 engineering priority와 검증 결과에 따라
지연되는 코어 이후 기능이다.

## 10. 검증 지표

가격보다 먼저 측정한다.

- milestone별 디지털 기억 제품 선택·완료율
- 디지털 초안 편집 완료율
- 실제 디지털·실물 주문 전환율
- 제품별 취소·환불·지원 부담
- 사용자가 직접 선택한 기록·사진·대화 비율
- Plus 후보 기능의 월간 반복 사용과 새로운 가치 체감
- iCloud quota 부족·복구·unlink 관련 지원 이슈

저장량·업로드량은 플랫폼 안전성과 운영 판단을 위한 참고 지표일 수 있지만, 곰신로그가
저장용량을 판매하는 수익 모델의 근거로 삼지 않는다.

## 11. 이 문서의 유지

- 가격·상품·POD 원가가 바뀌면 이 문서를 갱신하고 초기 가설 표기를 유지한다.
- iCloud/CloudKit의 구현 계약은 ARCH-P6와 관련 architecture 문서가 소유한다.
- 제품 의도는 `PRODUCT_V3.md`, 구현 순서는 `ENGINEERING_ROADMAP.md`에서 확인한다.
- 실제 구현·배포·Production 상태는 이 문서에 추정해서 쓰지 않는다.
