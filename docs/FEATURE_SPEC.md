# 기능 명세서 — 통화 맥락 루프

- 기준: `docs/PRODUCT_PRD.md`
- 상태: 구현 기준 v2

## 1. 역할별 첫 경험

### 곰신 홈

목표는 정보를 정교하게 분류하게 하는 것이 아니라 순간을 잃지 않고 남기게 하는 것이다.

- 첫 우선순위: `오늘의 기록`
- 입력 안내: `무슨 일이 있었는지 · 어떤 마음이었는지 · 통화 때 듣고 싶은 말`
- 입력 방식: 지금 찍기, 사진·영상, 음성, 한 줄
- 공유 범위: 기본은 커플 공유, 선택 시 나만 보기
- 저장된 감정은 사용자가 확인·수정한 항목만 공유 브리핑에 사용

### 군화 홈

목표는 피드를 읽는 것이 아니라 통화 전 맥락을 복구하는 것이다.

- 활성 커플인 군화 홈 상단에 `통화 전 60초`를 고정한다.
- 사용자가 삭제하거나 다른 위젯 아래로 내릴 수 없다.
- 기존 타임라인·감정 흐름·요약 위젯은 상세 탐색용으로 아래에 유지한다.

## 2. 통화 전 60초 — 구현됨

### 2.1 입력 데이터

- 현재 사용자가 볼 권한이 있는 상대 기록만 사용한다.
- 작성자가 `나만 보기`로 저장한 기록은 입력 단계에서 제외한다.
- 기본 범위는 오늘을 포함한 최근 7일이다.
- 체크포인트가 있으면 이미 확인한 기록 ID를 제외하고, 이후에 동기화된 과거 시각의 기록도 놓치지 않는다.

### 2.2 핵심 맥락 선택

한 화면에 최대 3개만 표시한다. 우선순위는 다음과 같다.

1. `힘들었어`
2. `네 생각났어`
3. `이런 일이 있었어`
4. 질문표가 들어간 기록
5. `좋았어`
6. 가장 최근 기록

선택된 항목은 다시 시간순으로 정렬하여 하루의 흐름을 해치지 않는다.

각 항목에는 날짜, 시간, 실제 기록의 짧은 발췌, 원문 이동 버튼을 표시한다. 기록 내용이 없으면 사진·영상·음성 종류를 사실대로 설명한다.

### 2.3 먼저 알아둘 마음

- 힘든 기록이 있으면 해결책을 제시하지 말고 현재 상태를 먼저 물으라고 안내한다.
- 서로를 떠올린 기록, 특별한 일, 좋은 일은 실제 반응값에 근거한 문장만 사용한다.
- 감정 점수, 에너지 퍼센트, 진단성 표현은 사용하지 않는다.

### 2.4 첫마디

- 가장 중요한 실제 기록의 발췌를 이용해 질문을 만든다.
- 예: `“오늘 일이 정말 힘들었어” 이 일, 지금은 좀 괜찮아?`
- 질문은 사실을 단정하지 않고 상대가 설명할 여지를 남긴다.
- 항목을 누르면 질문의 근거 원문으로 이동하고 강조한다.

### 2.5 통화 체크포인트 — 구현됨

- 새 소식이 있을 때 `통화했어요 · 여기까지 확인`을 표시한다.
- 누르면 포함된 기록 ID와 확인 시각을 사용자·커플별 로컬 저장소에 저장한다.
- 다음 진입부터 해당 시각 이후의 기록만 새 소식으로 표시한다.
- 새 소식이 없어도 `최근 7일 다시 보기`로 복구할 수 있다.
- 체크포인트는 기록을 삭제하거나 서버 데이터를 변경하지 않는다.

현재 한계: 기기별 체크포인트이므로 다른 기기에는 동기화되지 않는다. 실제 사용 검증 후 P1에서 서버 동기화를 검토한다.

## 3. 곰신 기록 — 구현 및 개선

### 구현됨

- 글·사진·영상·음성·반응·감정 흐름
- 전송 실패 시 입력과 실패 파일 보존
- 오프라인 발송함
- 공유와 나만 보기
- 작성 중 `사실 · 마음 · 통화 때 듣고 싶은 말` 안내

### 다음 단계

기록 저장 전에 선택 가능한 하나의 의도만 추가한다.

- `통화 때 꼭 얘기하고 싶어`
- 선택 보조값: `그냥 들어줘 / 같이 생각해줘 / 답이 궁금해`

이 값은 자동 추론하지 않으며 곰신의 선택이 브리핑 우선순위보다 항상 앞선다.

## 5. 일정·할 일

일정은 통화를 위한 공통 사실 맥락이다.

- 날짜별 일정과 공동 할 일을 한 화면에서 확인한다.
- 공동 할 일은 빠른 추가, 시간, 담당, 완료 상태를 제공한다.
- 통화 브리핑에 모든 할 일을 넣지 않는다.
- 향후 `24시간 안의 중요한 공동 일정`만 한 줄로 포함하는 것을 검토한다.

세부 저장·권한 명세는 마이그레이션 `018_shared_tasks_and_trip_places.sql`을 따른다.

## 6. 여행

여행은 깊은 대화 이후 함께 결정하는 실행 공간이다.

- 여행 일차별 장소·주소·영업시간·방문 순서를 관리한다.
- 지도 캡처는 외부 서버에 올리지 않고 기기에서 OCR 처리한다.
- 필수 유료 지도 API 없이 작동한다.
- 여행 세부 정보 전체를 통화 브리핑에 넣지 않는다.
- 향후 `결정이 필요한 여행 항목`만 통화 주제로 올리는 기능을 검토한다.

## 7. 상태와 오류

| 상태 | 표시 |
| --- | --- |
| 새 기록 있음 | 새 소식 수, 최대 3개 맥락, 마음, 첫마디, 완료 버튼 |
| 새 기록 없음 | 바로 안부를 물어도 좋다는 안내, 최근 7일 다시 보기 |
| 기록 동기화 확인 중 | 빈 상태로 단정하지 않고 확인 중 표시 |
| 커플 연결 안 됨 | 연결 안내, 브리핑 미노출 |
| 원문 없음 | 사진·영상·음성 종류를 사실대로 표시 |
| 로컬 저장 실패 | 체크포인트를 바꾸지 않고 기존 목록 유지 |

## 8. 개인정보와 안전

- 비공개 기록은 브리핑 입력·개수·감정·첫마디에서 완전 제외한다.
- 생리주기 정보는 어떤 통화 브리핑에도 자동 포함하지 않는다.
- 군번, 부대 위치, 작전 정보는 수집하거나 요약하지 않는다.
- 외부 AI 또는 분석 서비스로 기록 본문을 보내지 않는다.
- 분석 이벤트에는 기록 본문, 감정 라벨, 주소, 첨부 파일을 포함하지 않는다.

## 9. 수용 테스트

- 군화 계정에서 상단 고정 브리핑이 보이고 곰신 계정에는 보이지 않는다.
- 비공개 기록만 있으면 새 소식은 0개다.
- 최근 7일보다 오래된 기록은 첫 진입 브리핑에 포함되지 않는다.
- 중요 기록이 4개 이상이어도 화면에는 3개 이하만 보인다.
- 항목을 누르면 해당 원문으로 이동한다.
- 체크포인트 이후 이전 항목이 새 소식에서 사라진다.
- 최근 7일 다시 보기로 항목을 복구할 수 있다.
- 기존 기록·일정·여행 테스트가 계속 통과한다.
