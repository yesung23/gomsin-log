# 곰신로그 (GomsinLog) iPhone Safari PWA 파일럿 가이드

본 문서는 **`곰신로그` (군화와 곰신을 위한 1:1 비공개 데일리 로그 서비스)**의 iPhone Safari "홈 화면에 추가(Add to Home Screen)" 기반 PWA 웹 앱 파일럿 설치 및 테스트 지침서입니다.

---

## 1. 파일럿 성격 고지

> ⚠️ **PWA 파일럿 배포 성격**:
> 1. 본 배포는 App Store 정식 출시 전 **iPhone Safari "홈 화면에 추가" 기능을 활용한 독립 웹 앱(Standalone PWA) 파일럿**입니다.
> 2. 설치 후 실행 시 Safari 주소창과 상하단 브라우저 UI가 제거되고, 네이티브 앱과 동일하게 독립 창으로 실행됩니다.
> 3. 현재는 **로컬 데모 모드(`LocalStorageRepository`)**로 동작하며, 데모 데이터는 기기의 브라우저 저장소(`localStorage`)에 저장됩니다.

---

## 2. iPhone Safari 설치 가이드 (공유 → 홈 화면에 추가)

### 📱 설치 단계 (iOS Safari)
1. **iPhone Safari** 브라우저에서 배포된 서비스 URL 접속.
2. 화면 하단 중앙의 **공유 버튼** (<span style="color:#E87A6E;">[↑]</span> 아이콘) 클릭.
3. 공유 메뉴 목록을 아래로 스크롤하여 **'홈 화면에 추가'** (<span style="color:#E87A6E;">[+]</span> 아이콘) 선택.
4. **'웹 앱으로 열기'** 옵션 확인 후 우측 상단 **'추가'** 클릭.
5. iPhone 홈 화면에 곰신로그 **하트 아이콘** 생성 확인 및 클릭하여 실행.

---

## 3. 데모 데이터 및 PWA 한계 주의사항

- **기기/브라우저 저장소 의존**: 데모 모드의 모든 기록은 해당 iPhone 브라우저 `localStorage` (`gomsinlog.state.v1`)에만 유지됩니다.
- **데이터 소실 가능 상황**:
  - Safari 브라우저 방문 기록/쿠키/사이트 데이터 완전 삭제 시
  - 홈 화면 웹 앱 아이콘을 삭제 후 재설치할 경우
  - 다른 기기나 다른 브라우저(Chrome, Kakao In-App Browser 등)로 접속할 경우
- **실시간 상대방 동기화 미지원**: 현재 데모 모드에서는 곰신/군화 역할 전환(`switchRole`)으로 1:1 체험을 시뮬레이션하며, 실제 서버 DB(Supabase) 연동 전까지 두 대의 다른 스마트폰 간 실시간 데이터 동기화는 제공되지 않습니다.
- **푸시 알림 (Push Notification)**: 파일럿 범위에는 웹 푸시 알림이 포함되지 않습니다. (추후 Web Push / APNs 연동 예정).

## 4. PWA 파일럿 테스트 체크리스트

다음 항목을 검증하여 파일럿 테스트를 진행합니다.

- [ ] **1. iPhone Safari URL 접속**: 주소창/하단바 정상 표시 및 390px 반응형 프레임 확인
- [ ] **2. 설치 안내 팝업 확인**: iOS Safari 미설치 진입 시 설치 가이드 배너 표시 확인
- [ ] **3. 안내 닫기 정책**: 닫기(`✕`) 클릭 시 `gomsinlog.pwa_install_dismissed` 저장되어 재노출 안 됨 확인
- [ ] **4. 홈 화면에 추가**: iPhone 홈 화면에 '곰신로그' 아이콘 정상 추가
- [ ] **5. Standalone 실행**: 홈 화면 아이콘 클릭 시 주소창 없는 독립 스탠드얼론 앱 창으로 실행
- [ ] **6. Safe-Area 상하단 여백**: iPhone Notch / Dynamic Island 및 하단 Home Indicator 바와 탭 바 겹침 없음 확인
- [ ] **7. Standalone 모드 배너 숨김**: 독립 앱 실행 시 설치 안내 배너가 절대 노출되지 않음 확인
- [ ] **8. 5탭 이동 및 새로고침**: 홈 / 기록 / 우리 / 복무 / 마이 탭 간 이동 및 재접속 시 데이터 유지 확인
- [ ] **9. 기록 작성 및 달력 아카이브**: 기록 작성 후 오늘 타임라인 반영 및 기록 탭 월간 달력 날짜별 선택 동작 확인
- [ ] **10. 1280px 데스크톱 호환**: 데스크톱 환경 접속 시 중앙 430px 모바일 프레임 유지 확인
