# 2계정 수동 테스트 (비개발자용)

앱의 핵심은 **두 사람이 서로 연결된 비공개 공간**입니다. 이건 혼자서는 확인할 수
없어서, 계정 2개로 직접 해 봐야 합니다.

> ✅ 자동 테스트 625개 / 47개 파일이 통과하고, 실제 Chromium 에서 역할·테마·해상도
> 12조합 인터랙션 매트릭스(433개 확인 항목)도 통과했습니다. 하지만 **둘 다 목(mock)
> 기반입니다** — `page.route` 로 `https://example.supabase.co` 응답을 가로채고 세션을
> localStorage 에 심습니다. 즉 검증된 것은 **클라이언트 코드가 각 서버 응답에 대해
> 올바른 상태와 올바른 한국어 문구에 도달하는지**까지입니다.
>
> **실제 서버가 규칙을 강제하는지**(2계정 RLS, Storage 정책, Edge 런타임, 초대 코드
> throttling)는 아래를 사람이 직접 해야만 확인됩니다. **아직 실행되지 않았습니다.**

---

## 준비

- 이메일 계정 2개 (또는 구글 계정 2개)
- 기기/브라우저 2개
  - 같은 컴퓨터라면 **일반 창 + 시크릿 창** 으로도 됩니다.
  - 더 정확히 하려면 **다른 브라우저**(크롬 + 파이어폭스)를 쓰세요.
- 아래에서 A = 곰신 역할, B = 군화 역할

각 항목은 **기대 결과가 나오면 ✅, 다르면 ❌ 와 무슨 일이 났는지** 적으세요.
